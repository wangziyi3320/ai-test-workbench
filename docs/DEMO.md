# 3 分钟演示路径

以下样例均为虚构数据，可以安全公开。

1. 启动服务并打开网页。点击“载入示例”，保存需求。
2. 选择“离线规则模式”并生成用例。指出每条用例的来源原文、默认待审核状态，以及边界草稿中需要人工补充的部分。
3. 点开“编辑 / 审核”，把一条用例的步骤和预期改成可观察的表述，设为“审核通过”。
4. 导出 CSV，打开确认只含审核通过的用例。
5. 使用“导入 .json”上传 `sample_data/short_link_openapi.json`，生成接口用例，审核通过一条包含 HTTP 201 的正常用例。
6. 导出 Postman Collection，展示 `{{base_url}}/api/links` 和 HTTP 201 断言；说明请求体、Header 和授权仍需按实际接口补全。
7. 记录一条关联该用例的虚构缺陷，把状态从“待修复”改成“已修复”。
8. 若有自己的模型 API Key，再演示“模型 API 模式”；无 Key 时保留离线演示即可。

建议录制 2–3 分钟屏幕视频，遮挡真实密钥、公司接口地址、个人数据；演示过程不要把虚构缺陷说成真实项目成果。
